# writing-stock

このフォルダは、「現場屋の自力経営」の執筆用内部ストックです。

以下を保存します。

- 未公開記事の下書き
- 連載全体の章構成
- 記事化する前の実話メモ
- SNSへの切り抜き候補

## 運用ルール

- 本番サイトから参照・公開しない。
- 公開記事は従来どおり `content/articles/` で管理する。
- 記事を公開する際は、このフォルダの素材を確認し、必要な内容だけ公開記事へ昇格させる。
- 実話にない出来事・数字・成果は追加しない。
- 個人名、屋号、地域、取引先、顧客などを特定できる情報は公開原稿へ移す前に確認する。
- `sitemap.xml`、記事一覧、RSS、GA4の対象には含めない。
